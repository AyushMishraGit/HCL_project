# All-in-One Network Tracker

## Project Overview
All-in-One Network Tracker is a Python-based
network diagnostic application that combines
three essential networking tools into one
graphical desktop application.

## Features

1. IP Address Finder
   - Finds the IPv4 address of a website.

2. Ping Test
   - Checks network connectivity.
   - Displays ping responses and response times.

3. Traceroute
   - Displays the route taken by data packets.
   - Shows intermediate network hops.

4. Graphical User Interface
   - Easy-to-use desktop dashboard.
   - Input field and interactive buttons.

5. Export Network Reports
   - Saves network testing results as text files.

## Technologies Used

- Python 3
- Tkinter
- Socket
- Subprocess
- Threading

## Requirements

- Windows 10 or Windows 11
- Python 3.x
- Internet connection

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

python main.py

## Project Objective

To develop a simple and convenient network
diagnostic tool that combines IP address
lookup, ping testing and traceroute
functionality in one application.
